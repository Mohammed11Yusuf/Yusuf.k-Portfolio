## 🔗 Portfolio

**Live website:** Open `index.html` locally or deploy this repository with GitHub Pages.

## ✨ What It Showcases

- Embedded systems projects
- ESP32 / IoT development
- UAV and robotics work
- AI and software projects
- Engineering skills and certifications
- Academic and project experience

- HTML5
- CSS3
- JavaScript
- GSAP
- Three.js

## 🎨 Features

- Responsive layout
- Dark / light theme
- Animated hero section
- Interactive visual effects
- Project-focused portfolio sections
- Mobile-friendly navigation

## 🚀 Run Locally

```bash
git clone https://github.com/Mohammed11Yusuf/Yusuf.k-Portfolio.git
cd Yusuf.k-Portfolio
```

Open `index.html` in a browser.

For best results, serve the directory through a local HTTP server when using browser features that require it.
